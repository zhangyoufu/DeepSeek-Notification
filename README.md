# DeepSeek Notification

Somehow, DeepSeek does not provide any public document, showing their API platform announcement history.

This repo tries to [track every change](https://github.com/zhangyoufu/DeepSeek-Notification/commits/master/output.json) of their announcements (known as `xxxxxNotification` per their frontend code).

This repo alse serves an [Atom feed](https://zhangyoufu.github.io/DeepSeek-Notification/atom.xml) in case you need.
